# 📊 Sales Data Analysis Project

This project focuses on analyzing sales data to uncover business insights using **Python (Pandas, Matplotlib, Seaborn, Jupyter Notebook)** and **Power BI** for interactive visualization.

---

## 📁 Project Structure

- `sales_data.csv` → Raw sales dataset  
- `SalesDataAnalysis.ipynb` → Jupyter Notebook for data cleaning, exploration, and visualization  
- `sales analysis.pbix` → Power BI dashboard for interactive analysis  
- `README.md` → Project documentation  

---

## 🚀 Project Workflow

1. **Data Cleaning & Preprocessing**  
   - Handled missing values  
   - Standardized column names  
   - Converted dates and numerical values into proper formats  

2. **Exploratory Data Analysis (EDA)**  
   - Sales trends over time  
   - Regional and product-level performance  
   - Customer behavior and purchasing patterns  

3. **Visualization & Insights**  
   - Python plots: Sales trends, category-wise revenue, regional sales distribution  
   - Power BI dashboard: Interactive reports with filters and KPIs  

---

## 📌 Features

- End-to-end **Sales Data Analysis Pipeline**  
- **Jupyter Notebook** for transparent data processing and analysis  
- **Interactive Power BI Dashboard** for business-friendly insights
